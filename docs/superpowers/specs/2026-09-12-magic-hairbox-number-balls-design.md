# 魔法箱人數球 — 設計文件

日期：2026-09-12
狀態：已確認（使用者要求撰寫後直接執行）

## 1. 專案概述

美髮店叫號管理介面。150 顆號碼球，採平板／手機／電腦操作，即時鏡射實體叫號機台與剪髮進度。

- 球狀態：灰色（未下訂）、藍色（已下訂）、橘色（當前叫號）、外圈圓（過號尚未剪）、紅斜線（已剪）。
- 每球下方顯示「加總時間」與「預計時刻」兩種時間。
- 每日自動記錄藍球最大號碼，保留最近 3 個月（90 天），過期刪除。
- 支援全螢幕、封鎖雙擊縮放、僅直向捲動。

## 2. 技術方案

- 單一自包含 `index.html`（內嵌 CSS + 原生 JS），無建置、無框架、無外部依賴。
- 狀態以 localStorage 儲存（前綴 `mhb-`）。
- 部署：獨立 GitHub repo + Firebase Hosting（新專案一律獨立 repo，依 AGENTS 規則）。

## 3. 版面與響應式

- 直式佈局：**頂部說明欄（sticky，不隨捲動）** + 號碼球網格（可上下捲動）。
- 網格欄數依寬度自適應：手機直式約 4 欄、平板約 6 欄、電腦約 8~12 欄。
- 球大小用 `clamp()` 自適應，最小觸控點約 52px。
- 球間留 12~16px 縫隙 → 縫隙／空白處為捲動區；球上滑動＝動作。
- 頂部常態顯示目前實時時鐘（例 `15:00`），每秒更新。

## 4. 頂部說明欄（sticky、常態顯示、不可滾動）

```
快捷跳號: [20] [40] [60] [80] [100] [120] [140]
顏色: 灰=未下訂  藍=已下訂  橘=當前叫號  紅斜線=已剪  外圓=過號
手勢: ↑叫號  ↓基準時間  ←批量剪完  →下訂      ← 只說明滑動手勢，不寫「點球」
每球分鐘[15]  過號[開/關]  每日紀錄  每日重置  還原  全螢幕
```

- 手機過窄時允許換行／壓縮，但整塊不隨捲動。
- 手勢說明列**只寫 4 個滑動手勢**，「點球」完全不提（即使功能相同）。
- 快捷跳號按鈕點擊後捲動網格，使該號碼球位於可見區塊頂部附近。

## 5. 球狀態與外觀

| 狀態 | 外觀 | 時間顯示 |
|---|---|---|
| 尚未下訂 | 灰球 | 無 |
| 已下訂 | 藍球 | 顯示兩種時間 |
| 當前叫號 | 橘球 + 外光暈 | 顯示兩種時間（第 1 顆） |
| 過號尚未剪 | 藍球 + 深紅外圈圓 | 時間接在最後一段 |
| 已剪過 | 紅斜線蓋滿 | 不顯示時間、移出計算 |

- 外圈圓是藍球上的疊加狀態；一旦變紅斜線即移除外圈與時間。

## 6. 操作手勢

| 指法 | 動作 |
|---|---|
| 點球 | 批量下訂：點 58 → 1~58 全變藍（**只進不退**：N ≤ 目前 maxOrdered 時無作用） |
| 往右滑 | 同點球（功能相同，不列入說明欄文案） |
| 往上滑 | 該球＝當前叫號（橘）；上一個橘球自動變紅斜線；計算錨定到「現在」 |
| 往左滑 | 該號以前的藍 / 橘球全變紅斜線；**過號（外圓）球跳過不受影響** |
| 往下滑 | 開啟「基準時間設定」：預設帶入現在時間，可改，套用後整條時間重算 |
| 過號按鈕 開 | 點藍球 ↔ 外圓切換（設過號／取消過號） |
| 過號按鈕 關 | 點外圓球 → 直接變紅斜線（客人回來剪她） |
| 點紅斜線 / 灰球 | 無作用 |

## 7. 時間計算模型

- 每球 M 分鐘（預設 15，頂部可改，改動後全表重算）。
- **排隊順序**：藍 + 橘球照號碼遞增；過號球全部抽出、依號碼排在最後。
- 基準時間 T0 = 目前實時時間（頂部時鐘）。設定當前叫號時亦以「現在」為錨。
- 第 p 顆（1-based，**橘球當下也算第 1 顆**）：
  - 加總時間 = p × M 分鐘（例 13 顆 → 195 分 → 顯示「3小時15分」）
  - 預計時刻 = T0 + p × M
- 例：現在 15:00、13 顆未剪 → 第 1 顆 `${+15分} 15:15`、...、第 13 顆 `${+195分(3小時15分)} 18:15`。
- 例：叫號 18、過號 {10,12}、下訂到 58 → 第 1 顆 18（`+15分`），19..58 依序，之後接 10、12。
- 加總時間顯示格式：<60 分 → `45分`；≥60 分 → `3小時15分`。
- 狀態一變或頂部時鐘跳到下一分即自動重算。已剪（紅斜線）移出順序，後方時間自動提早。
- 過號球數量也會計入總數（下訂範圍內未剪者）。

## 8. 每日紀錄（3 個月）

- 每天記錄「當天最大藍色號碼」（＝當天剪髮總數）。
- 換日（過午夜或隔天重開）自動寫入前一天數字；「每日重置」也會先寫入當日後再清空。
- 記錄格式：`日期(yyyy-mm-dd) → 藍球數`。
- 保留最近 3 個月（90 天）記錄，過期自動刪除（「以月為記錄、過月刪除」）。
- 頂部「每日紀錄」按鈕 → 彈出列表顯示最近 90 天。

## 9. 資料儲存（localStorage）

狀態模型（單一物件，可推導全部 150 顆球狀態）：

| key | 內容 |
|---|---|
| `mhb-state` | `{ maxOrdered: int, current: int|null, overdue: int[], cut: number[], t0: "HH:MM", minutes: int, date: "yyyy-mm-dd" }` |
| `mhb-daily` | `{ "yyyy-mm-dd": int, ... }` 最近 90 天每日最大藍球號碼 |
| `mhb-history` | `[{op, n}, ...]` 當日操作歷史（最多 100 筆，供還原） |

- `cut` 為數字陣列（已剪紅斜線）。由 `maxOrdered`（順序下訂）、`current`、`overdue`、`cut` 四者即推導每顆球門面狀態。
- 每日重置：全部回灰（四欄清空）、寫入前一天紀錄、清空操作歷史、`date` 更新為今天。

## 10. 平板／觸控限制

- `<meta name="viewport" ... user-scalable=no maximum-scale=1>`。
- `touch-action` 控制：球網格 `pan-y`，單球元素 `none`（禁雙擊縮放與左右平移）。
- JS 對 `gesturestart`、`dblclick` preventDefault 以防縮放。
- 全螢幕用 Fullscreen API；不支援時自動隱藏按鈕。
- 捲動僅直向，消除左右漂移感。
- 滑動手勢偵測：touchstart/touchend，Δx/Δy 門檻約 30px 且軸向優勢判別；短位移視為點擊。

## 11. 操作歷史與還原

- 記錄當日操作歷史（最多約 100 筆）：每筆含 {type, number}。
- 「還原上一步」按鈕依序撤銷。

## 12. 部署

- 依 AGENTS 規則：獨立 repo、GitHub Pages + Firebase Hosting（site `mhb-sk`）。
- `firebase.json` 含 `"site": "mhb-sk"`；`.firebaserc` targets 對應。
- 在專案根目錄建立 `網址.txt`（GitHub URL + Pages URL + Firebase URL）。
- 每次修改後自動 commit + push + firebase deploy（AGENTS 自動部署原則）。
